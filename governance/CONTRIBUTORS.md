# Contributions by model

Record of who contributed what to this project. See `AGENTS.md` § Multi-agent contribution ingestion protocol for when and how to update this.

## Convention

Each contribution is recorded with:
- **Model/Person** — who generated the contribution
- **Date** — when
- **Type** — decision, code, documentation, analysis
- **Scope** — what was done, in one line

For content generated by a model that gets integrated as-is into code/docs, mark it with a callout at the start of the block:

```
> [!model]- Generated by [model name] — [context]
> (content here)
```
