# Decision Log

Record of non-obvious architecture/direction decisions and their reasoning.

Every new entry uses the next sequential number `D-XXX` — never reuse a number.

---

### D-000: Example format (delete once there are real decisions)

- **Decision:** [what was decided, in one sentence]
- **Date:** [YYYY-MM-DD]
- **Reason:** [why — what problem it solves]
- **Attribution by role:**
  - `proposed_by`: [model/person who raised it]
  - `implemented_by`: [who turned it into code]
  - `reviewed_by`: [who audited/challenged it]
  - `approved_by`: [who gave the final go]
- **Alternatives considered:** [A, B, C — one line each]
- **Status:** 🔵 Pending review · ✅ Accepted · ❌ Rejected · 🟡 Reverted
- **Implication:** [what changes in practice if this holds]
